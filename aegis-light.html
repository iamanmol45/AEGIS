How the gate decides

⋯
policy.py logic, not per-incident numbers
An action executes automatically only when the incident severity is CRITICAL, RCA confidence is at or above the minimum above, the current desired task count is below the max, and the cooldown window has elapsed since the last autonomous action. If any condition fails, the action is blocked and the incident is left for human review — this is the same gate every chaos scenario in this dashboard runs through.
